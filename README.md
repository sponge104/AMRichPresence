An Apple Music Rich Presence for Discord since it doesn't support it.

---

## Features

- Displays your current Apple Music track as a Discord Rich Presence
- Updates automatically as you play, pause, or skip tracks
- Shows track name, artist, album, and album art
- Lightweight and easy to use

## Installation

1. **Download the latest installer** from the [Releases](https://github.com/sponge104/AMRichPresence/releases) page.
2. Run `Setup.exe` and follow the instructions.
3. Launch AMRichPresence from the Start Menu or desktop shortcut.

## Usage

1. Open Apple Music and start playing a song.
2. Make sure Discord is running.
3. Start AMRichPresence.
4. Your Discord status will automatically update with your current track!

## Building from Source

1. Clone this repository:
    ```sh
    git clone https://github.com/sponge104/AMRichPresence.git
    ```
2. Open the solution in Visual Studio.
3. Restore NuGet packages if prompted.
4. Build the solution (Release or Debug mode).
5. The executable will be in the `bin/Release` or `bin/Debug` folder.
