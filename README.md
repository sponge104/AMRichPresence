## Features

- Displays your currently playing Apple Music track as your Discord Rich Presence
- Shows track name, artist, and album art (image display issues are known)
- Simple setup and lightweight

## Getting Started

### 1. Download and Install

- Download the latest release from [here](https://github.com/sponge104/AMRichPresence/releases/latest).
- Run the `Setup.exe` installer.

### 2. Usage

1. Start Apple Music/iTunes and play a track.
2. Launch the AMRichPresence application.
3. Your Discord status will update with your currently playing song.
